## About

Yacine Belalia is the Founder and CEO of **SCADAlgeria**. He builds cloud infrastructure for industrial automation, connecting operational technology (OT) to modern IT across edge computing, real-time data, and sovereign cloud systems for industry in Algeria and beyond.

## What is SCADAlgeria?

**[SCADAlgeria](https://www.scadalgeria.com)** is a **cloud-native SCADA (Supervisory Control and Data Acquisition) and IoT platform**, delivered as Software-as-a-Service (SaaS).

It connects physical assets to the cloud, where they can be monitored, controlled, and analyzed in real time. The same platform scales across the full range of users: an engineering student wiring up an ESP32 microcontroller, a maker running a home lab, and an industrial enterprise managing a 50,000-tag production line all work with the same tools.

## What the platform does

*   **Hardware agnostic** — Connects to legacy PLCs, RTUs, and modern IoT devices over Modbus, Siemens S7, OPC UA, and MQTT. Constrained microcontrollers such as the ESP32 and Arduino connect directly via firmware.
*   **Cloud-native and event-driven** — A microservices architecture built for horizontal scale and high-throughput MQTT ingestion.
*   **Real-time control** — Bidirectional telemetry and actuation streamed to WebGL-accelerated web dashboards at 60 fps.
*   **Edge resilience** — A local Edge Agent with store-and-forward buffering guarantees zero data loss during network outages.
*   **Security and governance** — Zero-Trust design, AES-256-GCM encryption, immutable cryptographically-anchored audit trails, and strict data governance.
*   **Built for Algeria** — Trilingual interface (Arabic, French, English), DZD-native billing, and a roadmap to in-country data residency.
